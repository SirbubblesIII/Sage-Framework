# SAGE Framework

This repository is the working home for Weston James Milhon's SAGE framework, SRP-CCC methodology, PKM/memory layer, and applied skill materials.

## Start Here

1. `SAGE_FRAMEWORK_CANONICAL_v2_2026-06-12.md` - current working canonical reference.
2. `SAGE_Framework_Core/SRP-CCC_SAGE_Update.md` - compact re-entry overview, changelog, and continuity/status log.
3. `SAGE_Framework_Core/DECISION_2026-06-12_Facets_to_Professions.md` - decision record for the profession-archetype / Core 11 pivot.
4. `SAGE_Methodology/srp_combinations.csv` - validated SRP method-combination matrix.

## Folder Map

- `SAGE_Framework_Core/` - core framework notes, decision records, outlines, persona/reference cards, and primary paper artifacts.
- `SAGE_Methodology/` - method matrices and structured reasoning data.
- `Skills_and_Applied/` - applied guides, skill drafts, templates, demos, and implementation-facing materials.
- `Working_Definitions/` - working-definition documents and cross-paper analysis.
- `Research_Sources/` - source lists and supporting research artifacts that should not clutter the root.
- `Adjacent_Projects/` - related but distinct projects, including the Experimental Cognitive Wrapper.
- `superseded/` - old drafts, duplicate uploads, and pre-v2 materials retained for lineage only.

## Version Notes

The June 12, 2026 v2 canonical is the current working reference, with its own stated caveat: v1 retains authority on conflicts until the translation test passes. The current personality-pillar framing is profession-archetypes curated by the Core 11 editorial board. Older seven- or nine-facet materials may still be historically useful, but should not override the current canonical.

The Experimental Cognitive Wrapper is adjacent to SAGE, not the SAGE framework itself. It lives under `Adjacent_Projects/` to keep that distinction visible.
